# EPAM Project - Practice Tasks

Practice tasks for automation at EPAM.

## Description

This is a generic repository used to store practical tasks made for EPAM Campus.

## Getting Started

### Choosing a branch

* You may use this command to switch to the correct branch:
```
git checkout <branch name>
```

* The following branches are available:
    - WDIO module: wdio-practice-task
    - Playwright module: playwright-practice-task
    - Cypress module: cypress-practice-task

* You may follow the next instructions once you have successfully switched branches.

### Dependencies

* Follow the instructions on https://nodejs.org/en/download to install Node.js.
* Run this command on the console to install all dependencies:
```
npm install
```
* No extra configurations are needed.

### Test Execution

* Run this command to execute the tests:
```
npm run test
```
